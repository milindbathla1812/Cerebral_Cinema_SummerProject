Multimodal Transformer Architecture

A lightweight Transformer predicts whole-brain fMRI activity by learning joint representations from language and visual features.

Overall Architecture

The Cerebral Cinema model integrates multimodal movie information by combining language and visual embeddings into a shared latent space. Temporal dependencies are modeled using a Transformer encoder, whose CLS representation is finally mapped to whole-brain activity across 1000 cortical parcels.

Model Components

🎭 Modality Dropout

Randomly masks one modality during training to improve robustness and reduce dependence on a single feature source.

📐 Linear Projection

Projects the concatenated 2816-dimensional multimodal embedding into a compact 384-dimensional latent space.

📍 Positional Encoding

Injects temporal ordering information into the sequence so the Transformer understands frame positions.

🧩 CLS Token

A learnable token aggregates information from the entire sequence and serves as the global representation.

Transformer Encoder

The Transformer encoder models long-range temporal dependencies across the multimodal sequence. Each encoder layer applies Multi-Head Self-Attention followed by a Feed Forward Network with residual connections and Layer Normalization.
